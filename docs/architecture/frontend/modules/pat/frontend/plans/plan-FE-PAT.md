## Project summary

The PAT frontend module delivers the **command catalog** (promoted Calibration screen) and the
**patient registration** form (onboarding patient step) for the `neuroassist-niv` caregiver-facing
Angular SPA. The module is lazy-loaded by the shell at `/patients*` and exposes two feature surfaces:
the per-patient command catalog (list, create, calibrate, retire) and the patient registration form.
The command editor is an in-page panel (no route), keeping draft state in feature-local signals until
save. All PAT actions are **pessimistic** — catalog correctness feeds the GEST detection engine and
must not drift. BE authorities are canonical (INV-PAT-8); two carry-forwards are hard rules: the HTTP
adapter must default to `http` (not mock), and no guard may hardcode `return true`.

## Top-3 risks

| # | Risk | Mitigation |
|---|---|---|
| R1 | BE `pat-service` endpoints not yet deployed → INT-FE-PAT-001..003 blocked | Use `MockAdapter` during development; switch to `http` default once pat-service is reachable (SPEC-04 §2 carry-forward already mandates the default is http) |
| R2 | Shared `@neuroassist/shared/access-decision`, `auth-session`, `access-http-base` libs not yet scaffolded → guards and adapter interceptor chain blocked | Shared libs are P0 of the scaffolding pipeline; PAT FE guards import them; if absent create stub providers in `pat.providers.ts` for local dev only (never in production path) |
| R3 | `getUserMedia` / webcam API unavailable in CI → `LiveWebcamTestComponent` tests fail | Use fake media stream stub in Playwright (`--use-fake-ui-for-media-stream`); Jest unit tests use a mock `mediaDevices.getUserMedia` |

## Definition of Done per wave

- **P1 done**: `npx nx build neuroassist-niv-web` PASS; sidebar renders "Patients & Commands" statically; `providePat()` spec proves HTTP default.
- **P2 done**: `npx nx test pat-data-access` PASS; all 13 BE endpoints covered by adapter unit tests; error mapper spec covers all 7 slugs.
- **P3 done** (MVP shippable in dev): `npx nx build pat-feature-command-catalog` PASS; catalog renders loading/empty/error states; editor validates all client-side invariants; registration page exists.
- **P4 done**: INT adapters tested against pat-service contract (or WireMock); no `X-Tenant-Id` leak; shell descriptor live.
- **P5–P8 done**: guards tested; breadcrumbs registered; 5 observability events verified; no `console.log`.
- **P9 done**: 25 Playwright stubs present (fixme/TODO); axe zero WCAG AA violations; PAT not in shell main bundle.
