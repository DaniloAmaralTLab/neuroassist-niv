## Contexto

Implements the schema-per-tenant routing infrastructure. `TenantJwtFilter` extracts
`tenantId` from the ACS JWT claim (never from `X-Tenant-Id` — INV-PAT-1) and stores it in
`TenantContextHolder` (ThreadLocal). `TenantRoutingDataSource` extends Spring's
`AbstractRoutingDataSource` to route each connection to the correct `t_<tenantId>` schema
via `SET search_path TO t_<tenantId>, neuroassist_global`. Global schema reads (gesture_type)
always see `neuroassist_global` via the `search_path` suffix. This is the prerequisite for
all repository adapters (PAT-011, PAT-012).
