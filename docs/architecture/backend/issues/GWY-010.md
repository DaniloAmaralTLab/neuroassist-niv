# GWY-010 -- PHI-free access log filter — emit method, route template, status, latency, correlationId ONLY; never body/params/identifiers (INV-G1, ADR-007)

**Status:** INTACT -- gerado 2026-11-22
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/4 itens

## Contexto

GWY is the most dangerous PHI surface: it sees every request across all modules.
Default access-log patterns can capture query strings (which may contain patient ids
or gesture data) and request bodies. This filter replaces any default access-log with
an explicit, fixed-format PHI-free record: HTTP method, **route template** (e.g.
`/hist/**` — not the concrete URI with identifiers), response status, latency ms, and
correlation id. The concrete path is intentionally omitted — the identifying detail
lives in HIST's audited trail, not at the edge. Implement as a `GlobalFilter` running
after the route is selected (so the route template is available) but before the
downstream call (latency measured end-to-end).

## Resultado esperado

A `GlobalFilter` that emits one structured log line per request with exactly five
fields: method, route template, status, latency, correlationId — and nothing else.

## Criterios de aceite

- [ ] AC-1 Each completed request emits exactly one log line containing method, route template (e.g. `/hist/**`), status code, latency in ms, and X-Correlation-Id
- [ ] AC-2 The concrete URI path (with concrete ids or query parameters) does NOT appear in the log line
- [ ] AC-3 Request body, response body, `Authorization` header value, and any identifier-bearing header do NOT appear in any log line produced by this filter
- [ ] AC-4 `./gradlew :neuroassist-niv-api-gateway:compileJava` exits 0
