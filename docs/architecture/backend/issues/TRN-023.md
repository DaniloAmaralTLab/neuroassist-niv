## Contexto
Implement the voice-cloning consent lifecycle (capture/read/revoke) and the broker-free durable-retry scheduler. `ConsentService.captureConsent()` requires both `grantedByPatient` and `grantedByRepresentative` to be `true`, creates a `granted` consent_record, and audits `ConsentGranted` via `AuditPort.auditHard502()`. `ConsentService.revokeConsent()` sets status=`revoked` locally (committed), then enqueues a `ConsentRevoked` audit as a durable-retry job (commit+durable-retry — HIST outage must NOT block local revocation). `OutboundJobDispatcher` is the Spring `@Scheduled` poller that picks up `pending` outbound_job rows and dispatches them by `job_type`.
