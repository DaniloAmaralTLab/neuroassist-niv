# TRN-021 -- TenantContextFilter + ServiceClientTokenProvider — filter ORDER after BearerTokenAuthenticationFilter (RULE-04); TRN service-client token for outbound CONV/PAT/HIST calls (SPEC-06)

## Contexto
Implement `TenantContextFilter` to extract the `tenantId` claim from the validated JWT and populate `TenantContextHolder`. Register the filter inside the `SecurityFilterChain` AFTER `BearerTokenAuthenticationFilter` (RULE-04 — the tenant claim can only be extracted after the token is validated). Every application service must call `TenantContextHolder.require()` as its first line. `ServiceClientTokenProvider` obtains the TRN service-client token (minted by ACS with the five cross-service authorities: `conv.tree.publish`, `conv.tree-version.retire`, `conv.audio.delete`, `hist.audit.record`, `pat.patient.read`) used for all outbound CONV/PAT/HIST calls.
