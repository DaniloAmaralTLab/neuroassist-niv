# REG-004 -- Pin Spring Cloud Netflix Eureka Server version compatible with project Spring Boot 21 line

**Status:** INTACT -- gerado 2026-11-22
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/3 itens

## Contexto
Spring Cloud Netflix Eureka Server's release train must be aligned with the Spring Boot version the project uses (Spring Boot 3.x / Java 21). An incompatible version causes startup failures or classpath conflicts. This issue pins the Spring Cloud version in the Gradle build and validates that all in-fleet client services use a compatible `spring-cloud-starter-netflix-eureka-client` version.

- [ ] verify BOM declaration in root `build.gradle.kts` or `gradle/libs.versions.toml` pins `spring-cloud` to a version tested against Spring Boot used in the project
