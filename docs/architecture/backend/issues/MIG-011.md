## Contexto

V0005 is the only MIG-authored tenant-scoped script. It runs against every t_<tenantId> schema. Its purpose is minimal: add a schema comment to mark the schema as a valid NeuroAssist NIV tenant schema and confirm that the global search_path is correctly configured (neuroassist_global is accessible). It does NOT re-install extensions (they live in neuroassist_global on the search_path, INV-MIG-5). Business tables are authored by each module in its own reserved block. Blocks V0006-V0009 are reserved for future baseline housekeeping.
