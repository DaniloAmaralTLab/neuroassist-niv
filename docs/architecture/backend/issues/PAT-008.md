## Contexto

Implements `CalibrateCommand(commandId, <partial>)` in the application layer. The pseudocode
in SPEC-02 must be followed exactly: load from tenant (→ 404 if absent), reject if `retired`
(→ 409 `command-retired`, INV-PAT-5), apply changed fields, re-validate window and
composition (INV-PAT-3/4), bump `updatedAt`, save, audit `CommandCalibrated(changeKind=recalibrated)`.
A no-op PATCH (nothing changed) MUST return 200 without calling `HistAuditPort` (SPEC-05).
Optimistic concurrency: JPA `@Version` on the entity; a stale-state exception translates to
a retry-able error at the API layer. SPEC-05 §CalibrateCommand idempotency table.
