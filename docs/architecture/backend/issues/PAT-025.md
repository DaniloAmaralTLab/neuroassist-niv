## Contexto

Hardens PAT's ACS dependencies. `JwksRefreshScheduler` runs a scheduled JWKS refresh (e.g.,
every 5 min) so the cache stays current without waiting for a request to trigger a refresh;
exposes a Micrometer gauge `pat_jwks_cache_stale` to signal degraded state when JWKS is
unreachable. Resilience4j `CircuitBreaker` on the ACS introspection call (integration-contracts
§1 fallback): open circuit allows standard JWT validation to proceed (best-effort revocation,
logged). Circuit breaker on HIST audit call: open circuit returns `502` in prod (event-contracts
§1). `application.yml` configures both circuit breakers.
