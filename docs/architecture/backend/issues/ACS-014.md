# ACS-014 -- Spring Data JPA repositories + repository adapters (6 adapters, findById-before-save for Persistable<UUID>)

## Contexto

Spring Data JPA `JpaRepository` interfaces and hexagonal adapters that implement the
outbound ports (ACS-003). Critical rule per pitfall
`jpa-entity:generated-value-preassigned-uuid:hibernate6-detached-entity-error`:
the `save` method in every adapter must call
`repository.findById(id).orElseGet(XJpaEntity::new)` before assembling the entity, so
Hibernate does not mark an update as a new insert (which causes duplicate key on the PK).

The `CaregiverIdentityLookupJpaRepository` queries the **global** schema
(`neuroassist_global`); the other per-tenant repos query the tenant schema
(`t_<tenantId>`). Schema routing is handled by a `TenantSchemaResolver` in the Spring
configuration (not by the adapter directly). The adapter should use `@Transactional` only
in the application service layer (RULE — no @Transactional in infrastructure adapters).
