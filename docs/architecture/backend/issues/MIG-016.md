# MIG-016 -- Per-schema progress reporting + structured logs (SPEC-07)

**Status:** INTACT -- gerado 2026-11-22
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/4 itens

## Contexto

MIG has no HTTP health endpoint (non-web job). Its health signal is the exit code and the per-schema log report. After every pass sequence MigrationsJobRunner logs one line per schema (name, from-version → to-version, OK / FAILED / SKIPPED) at INFO or ERROR. Ops reads this log to confirm success. The lifecycle start line (mode + arguments) and final summary line are also required by SPEC-07.

## Spec de referencia
- SPEC-07 (per-schema report, exit code contract, structured logs)

## Escopo
- `services/neuroassist-niv-migrations/src/main/java/com/neuroassist/migrations/application/MigrationReport.java` — value class: schema, fromVersion (nullable), toVersion (nullable), outcome (OK | FAILED | SKIPPED), failureMessage (nullable)
- Update `services/neuroassist-niv-migrations/src/main/java/com/neuroassist/migrations/application/MigrationsJobRunner.java` — log start line at INFO (mode + args); after all passes, log one MigrationReport line per schema at INFO/ERROR; log summary at INFO
- `services/neuroassist-niv-migrations/src/test/java/com/neuroassist/migrations/application/MigrationReportLogTest.java` — unit test: global failed → ERROR log with schema name; tenant failed → all prior schemas OK, failing schema ERROR, rest SKIPPED

## Resultado esperado

A run log line format: `[MIG] schema=neuroassist_global from=V0004 to=V0004 outcome=OK` or `[MIG] schema=t_unitA from=V0005 to=V0020 outcome=OK`. On failure: `[MIG] schema=t_bad from=V0005 to=? outcome=FAILED message=<Flyway error>`.

## Criterios de aceite
- [ ] AC-1 Start line logged at INFO: mode and tenantId (if applicable) before any DDL
- [ ] AC-2 After all passes: one log line per schema at INFO (OK/SKIPPED) or ERROR (FAILED)
- [ ] AC-3 On global failure: neuroassist_global logged ERROR; all tenant schemas logged SKIPPED
- [ ] AC-4 Final summary line at INFO: "Migrations complete: global=[OK|FAILED] tenants=[n ok / n failed / n skipped]"
