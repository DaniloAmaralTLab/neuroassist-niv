## Contexto

Two related services consumed by other resource servers:
1. `IntrospectService.introspect(token)` — validates the JWT signature, checks expiry (or lack
   thereof for patient-session tokens), then calls `TokenBlacklistPort.isBlacklisted(jti)`;
   returns `active=true/false` with claims when active.
2. The JWKS endpoint (`/acs/.well-known/jwks.json`) is public; the `JwksController` (created in
   ACS-018) calls a service method to retrieve the active signing key set.
Resource servers call these on each request to enforce revocation; the JWKS endpoint feeds the
`spring.security.oauth2.resourceserver.jwt.jwk-set-uri` configuration of every other service.
