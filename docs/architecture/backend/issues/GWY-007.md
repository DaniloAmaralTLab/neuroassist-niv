## Contexto

Configures GWY as a Eureka client so that `lb://` route targets are resolved via the
service registry (REG at `:8761`). Routes are **declared explicitly** in R1..R8 (GWY-002),
not auto-located by Eureka's discovery locator (`spring.cloud.gateway.discovery.locator.enabled:
false`). Without this setting, the locator would auto-create routes for every registered
service, bypassing the route table and the security posture. The `defaultZone` uses an
env fallback `${EUREKA_URI:http://localhost:8761/eureka}` to allow easy override in
containerized deployments.
