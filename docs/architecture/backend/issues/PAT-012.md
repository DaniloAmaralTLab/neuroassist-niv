## Contexto

Implements the `GestureType` JPA entity reading from the global schema `neuroassist_global`
(not tenant-scoped). The `MultiTenantSchemaRouter` determines at runtime whether to route a
query to the global schema or the per-tenant schema `t_<tenantId>`. `GestureTypeJpaEntity`
maps to `gesture_type` with `@Table(schema = "neuroassist_global")`. The uniqueness constraint
on `code` must be honored at the application layer (409 on duplicate) since the DB `UNIQUE`
constraint will also reject it. ETag computation for `GET /pat/gesture-types` uses
`max(created_at)` + count from this repository.
