**Status:** INTACT -- gerado 2026-11-22

## Contexto
The prod profile pins the self-preservation posture as an explicit decision (ADR-001: open in architecture, resolved at config time). Self-preservation prevents mass eviction when a network blip causes many clients to miss heartbeats simultaneously. This issue creates the prod profile file so the service can be started with `SPRING_PROFILES_ACTIVE=prod` to enable it.
