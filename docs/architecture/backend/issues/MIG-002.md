# MIG-002 -- MigrationMode enum + fail-fast argument validation (SPEC-01)

**Status:** INTACT -- gerado 2026-11-22
**Maturidade:** 0 -- Inicial

## Contexto

MIG accepts exactly one run mode per invocation (SPEC-01). Before any DDL is touched the runner must parse the String[] args, detect the mode, validate tenantId presence for TENANT/PROVISION_TENANT modes, and exit 1 on any usage error. This is the fail-fast gate that makes every subsequent pass safe to run.

## Spec de referencia
- SPEC-01 (run modes, argument validation, exit codes)

## Escopo
- `services/neuroassist-niv-migrations/src/main/java/com/neuroassist/migrations/api/MigrationMode.java` — enum ALL, GLOBAL_ONLY, TENANT, PROVISION_TENANT
- `services/neuroassist-niv-migrations/src/main/java/com/neuroassist/migrations/api/MigrationArgParser.java` — parses String[] args into MigrationMode + optional tenantId; throws MigrationUsageException on invalid input
- `services/neuroassist-niv-migrations/src/test/java/com/neuroassist/migrations/api/MigrationArgParserTest.java` — unit tests for all valid and invalid argument combinations

## Resultado esperado

MigrationArgParser correctly parses --all, --global-only, --tenant <id>, --provision-tenant <id> and rejects: no args, >1 mode, --tenant without id, --provision-tenant without id, malformed tenantId (non-alphanumeric/hyphen chars that would yield an invalid schema name).

## Criterios de aceite
- [ ] AC-1 --all, --global-only parse to their respective MigrationMode values with no tenantId
- [ ] AC-2 --tenant unitA and --provision-tenant unitA parse with tenantId="unitA"
- [ ] AC-3 No args, two simultaneous modes, and missing tenantId each throw MigrationUsageException
- [ ] AC-4 `./gradlew :services:neuroassist-niv-migrations:test` exits 0 (unit tests pass)
