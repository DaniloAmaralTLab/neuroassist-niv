## Contexto

Implements the correlation-id propagation contract (INV-G4, ADR-007). Every request
entering the gateway either carries an `X-Correlation-Id` (preserved verbatim) or
receives one (UUID v4 generated). The id is set in the Reactor context / MDC so that
all log lines emitted while processing that exchange carry it, forwarded downstream in
the mutated request, and echoed back in the response header. The filter runs at the
highest precedence to ensure MDC is populated before any other filter logs.
GWY is WebFlux — implement as a `GlobalFilter` + `Ordered` (order `Ordered.HIGHEST_PRECEDENCE`).
