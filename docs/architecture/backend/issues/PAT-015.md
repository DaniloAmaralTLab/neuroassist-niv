## Contexto

Implements `HistAuditAdapter` which adapts `HistAuditPort`: calls `POST {hist.baseUrl}/audit`
synchronously (RestTemplate or WebClient) with the envelope from `event-contracts.md §1.1`.
Propagates `X-Correlation-Id` from MDC on every call. Current policy (pending INT-PAT-002
confirmation): on HIST failure in production, the use case rolls back and returns `502 Bad
Gateway`; in dev profile (`spring.profiles.active=dev`), degrades to log-only. Service
discovery via REG (Eureka); direct `hist.base-url` as fallback. `X-Correlation-Id` echoed
from MDC context (PAT-020 sets the MDC value).
