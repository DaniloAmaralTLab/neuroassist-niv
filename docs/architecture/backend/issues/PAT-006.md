## Contexto

Implements `PatientService.register(label, deviceId?)` in the application layer: persists an
`active` patient with `tenantId` from JWT (INV-PAT-1), `createdBy` from JWT `sub`, then calls
`HistAuditPort` to record `PatientRegistered` before returning. Also implements `deactivate`
and `reactivate` operations on `PatientService` with idempotent semantics (re-deactivate of
`inactive` → 204 no audit; reactivate of `active` → 200 no audit). All use cases use
`@Transactional` only within the application layer. Test uses Mockito stubs for ports.
