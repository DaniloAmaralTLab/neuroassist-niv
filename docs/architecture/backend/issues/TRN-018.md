## Contexto
Implement `ElevenLabsTtsAdapter` and `SubjectKeyService`. `SubjectKeyService` manages the per-subject crypto key for each patient's voice data: all `storage_ref` and `voice_model_ref` values in `audio_asset` / `voice_model` are stored encrypted under this key (ADR-005). `ElevenLabsTtsAdapter` calls the ElevenLabs API to synthesize a phrase, checks for a granted `ConsentRecord` before **every** call (INV-TRN-3), stores the result as an `audio_asset` row under the per-subject key, and never creates a partial `audio_asset` row on failure.
