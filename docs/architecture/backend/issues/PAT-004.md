## Contexto

Creates the `GestureType` aggregate (global vocabulary — `neuroassist_global` schema, ADR-002)
and three cross-cutting domain ports. `GestureType` is append-only in the MVP: a code is a
name in the vocabulary only — PAT asserts no detection-engine support (INV-PAT-6, GEST owns
that truth). `GestureTypeRepository` queries global schema regardless of tenant. The three
ports (`HistAuditPort`, `TokenValidationPort`, `AcsIntrospectionPort`) complete the domain
boundary so application-layer use cases can depend on interfaces only.
