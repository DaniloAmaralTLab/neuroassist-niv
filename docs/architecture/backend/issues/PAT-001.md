**Status:** INTACT -- gerado 2026-11-19
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/8 itens

## Contexto

Foundation issue. Creates the four-layer package skeleton (`api` / `application` / `domain` /
`infrastructure`) for `pat-service` and the Gradle build file with the `integrationTest`/`test`
split. Without `tasks.test { exclude("**/*IT.class") }`, the plain `test` task picks up
`CucumberIT` and similar IT classes, causing Spring context failures for every unimplemented
port. `application.yml` wires port 8082, Eureka and datasource stubs (MIG applies Flyway;
`spring.flyway.enabled=false` here). ADR: `docs/architecture/backend/adr/ADR-001-hexagonal-architecture.md`
(key `hexagonal_java`).
