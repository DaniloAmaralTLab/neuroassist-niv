## Contexto

The `RoleAuthorityPolicy` class is the SINGLE source of authority strings for both
`@PreAuthorize` annotations (controllers) and test token builders (BDD/IT). Without it,
authority strings drift between the two sides and produce silent 403s (D-535, INV-7, risk
bdd-scaffold:authority-strings:controller-preauthorize-mismatch-roleauthoritypolicy).
Seven authorities to declare: `acs.caregiver.create`, `acs.caregiver.deactivate`,
`acs.patient-link.link`, `acs.patient-link.unlink`, `acs.patient-session.provision`,
`acs.patient-session.revoke`, `acs.tenant.onboard`.

DTOs are Java records (immutable). Error model: `ProblemDetailFactory` returns
`ResponseEntity<ProblemDetail>` with explicit `pd.setStatus()` for each code
(pitfall: exception-handler:plain-problem-detail:wrong-http-status — bare `ProblemDetail`
returns HTTP 500 for all codes). Error slugs: invalid-credentials, unauthenticated,
forbidden, not-found, username-taken, link-exists, validation-error.
