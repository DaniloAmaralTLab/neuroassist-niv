## Contexto

Implements JPA entities and Spring Data repositories for `patient` and `command` tables
(per-tenant schema `t_<tenantId>`). `CommandJpaEntity` carries `@Version` for optimistic
concurrency (SPEC-05). `PatientRepositoryAdapter` and `CommandRepositoryAdapter` implement
the domain `PatientRepository` / `CommandRepository` ports. Per-tenant routing is achieved
via the `TenantRoutingDataSource` (PAT-016); entities use the tenant's schema via
`search_path`. No FK across service boundaries — `deviceId`, `createdBy`,
`primaryPrimitiveId` / `secondaryPrimitiveId` are stored as `UUID` without JPA FK mapping
(data-model §1 convention).
