## Contexto

The authentication golden path: given `username` + `password`, the service
1. looks up `caregiver_identity_lookup` by `username` (global schema) to resolve the tenant (INV-6),
2. loads the `caregiver` row from the tenant schema to verify `password_hash` and `status`,
3. rejects if `status = DEACTIVATED` with the same error as bad credentials (no user enumeration),
4. mints a caregiver JWT carrying `sub`, `tenantId`, `actorType=caregiver`, `authorities` from `RoleAuthorityPolicy` per the caregiver's role,
5. audits `CaregiverAuthenticated` to HIST.
The `TokenIssuerPort` abstracts JWT signing; `HistAuditPort` abstracts the audit call.
