## Contexto
Liveness (`/actuator/health`) confirms the server process is up. Readiness (`/actuator/health/readiness`) reflects whether the registry is accepting registrations. These endpoints are essential for container orchestration health checks and for the ops operator to confirm REG is functional before starting the fleet.
