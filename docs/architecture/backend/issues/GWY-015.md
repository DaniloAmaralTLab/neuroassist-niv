## Contexto

Provides the shared integration-test base class for all GWY BDD and IT tests.
**GWY is a full web service** (gateway — it handles incoming HTTP requests), so
`webEnvironment = RANDOM_PORT` is correct. This is the opposite of non-web
services (REG/MIG) which ran into the wrong-webEnvironment defect: for GWY,
using `NONE` or `MOCK` would prevent the gateway from accepting test HTTP requests.
WireMock stubs stand in for all 8 downstream services and the two JWKS endpoints.
The base class wires the `webTestClient` on the random port and starts WireMock
server instances per downstream so test traffic never reaches real services.
