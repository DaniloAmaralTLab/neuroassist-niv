## Contexto
Implement the right-to-be-forgotten erasure (SPEC-11 §7, ADR-005/006). `DELETE /trn/patients/{id}/content` orchestrates: (1) delete the ElevenLabs voice model (`TtsPort.deleteModel()`), (2) delete the per-subject crypto key (`SubjectKeyService.deleteKey()`), (3) mark `voice_model`/`voice_sample`/`audio_asset` rows erased, (4) enqueue durable-retry `outbound_job` entries for `conv.tree-version.retire`, `erase_conv_audio`, `VoiceModelDeleted` audit, and `ContentErased` audit. Steps 4+ are durable-retry (ADR-007): a HIST or CONV outage must **not** block the local erasure (INV-TRN-9). Response is `202 Accepted` with erasure counts. The endpoint is idempotent: a second DELETE for an already-erased patient returns `202` with zero counts.
