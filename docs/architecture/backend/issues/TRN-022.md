## Contexto
Integration test proving that `@PreAuthorize` is enforced (D-642 requirement). Without `@EnableMethodSecurity(prePostEnabled=true)` the annotations are silently inert — no compile error, no startup failure, everything just lets through. This test covers three axes: (1) each protected endpoint returns `403` when the required `trn.*` authority is absent, (2) `GET /trn/health` returns `200` without any token, and (3) a patient-session token (with `conv.*`/`gest.*` authorities only) is rejected `403` on every protected endpoint (ACS INV-3).
