# ACS-021 -- Actuator + custom health indicators (PostgreSQL, HIST endpoint) with @ConditionalOnProperty in test profile

**Status:** INTACT -- gerado 2026-11-19
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/3 itens

## Contexto

Exposes Spring Boot Actuator endpoints for health, info and metrics. Two custom
`HealthIndicator` beans probe real infrastructure:
- `DatabaseHealthIndicator` — pings the PostgreSQL global schema.
- `HistHealthIndicator` — pings `{hist.baseUrl}/actuator/health` (or GET root).

Both indicators MUST be guarded by `@ConditionalOnProperty` (pitfall
`observability:health-indicator:missing-conditional-on-property-in-test`): without it,
each indicator tries to reach live infrastructure during unit/integration tests that do not
start the full docker compose stack, turning the test-profile Spring context health DOWN
and potentially failing the boot.

Corresponding `application-test.yml` disables both:
```
management.health.hist.enabled: false
management.health.database.enabled: false
```
