# REG-005 -- Restrict Eureka dashboard and protocol to internal network; verify no public route in GWY

**Status:** INTACT -- gerado 2026-11-22
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/4 itens

## Contexto
REG's security posture is network-trust: the Eureka registration/discovery plane and the dashboard are internal-only. The API Gateway (GWY) must have no public route pointing to REG's Eureka endpoints. The dashboard must not be exposed to the public internet. REG makes no auth decision — it validates no edge JWT and reads no tenant context.

## Spec de referencia
- SPEC-06 (Security)

## Escopo
- [ ] update `src/main/resources/application.yml` — configure Spring Security to permit `/actuator/health` and `/actuator/health/readiness` without credentials; restrict `/` (dashboard) and `/eureka/**` to network-internal access only (or allow-all with network enforcement documented)
- [ ] implementar `src/main/java/com/neuroassist/registry/config/ActuatorSecurityConfig.java` — `@Configuration @EnableWebSecurity`; permit `GET /actuator/health`, `GET /actuator/health/readiness`, `GET /actuator/prometheus`; document that Eureka protocol endpoints rely on network isolation (no JWT filter, no tenant context)
- [ ] add comment in config class: "REG validates no edge JWT; isolation is by network topology (SPEC-06, ADR-001)"
- [ ] verify GWY config has no route matching `/eureka/**` or `/` targeting REG
