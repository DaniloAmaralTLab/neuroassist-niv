# MIG-013 -- TenantSchemaEnumerator — list t_* schemas from information_schema (SPEC-03)

**Status:** INTACT -- gerado 2026-11-22
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/3 itens

## Contexto

The --all mode must discover which tenant schemas exist without a central tenant registry (gap G3 is open; MVP uses information_schema). TenantSchemaEnumerator queries information_schema.schemata for schemas matching the configured prefix (default t_). Zero results is a valid return value: --all with no tenants runs only the global pass and exits 0.

## Spec de referencia
- SPEC-03 (tenant enumeration from information_schema, G3 gap open)

## Escopo
- `services/neuroassist-niv-migrations/src/main/java/com/neuroassist/migrations/infrastructure/TenantSchemaEnumerator.java` — queries information_schema.schemata WHERE schema_name LIKE 't\_%'; reads MIG_TENANT_SCHEMA_PREFIX env (default t_); returns List<String>
- `services/neuroassist-niv-migrations/src/test/java/com/neuroassist/migrations/infrastructure/TenantSchemaEnumeratorTest.java` — Testcontainers: empty DB returns empty list; two schemas t_unitA and t_unitB are enumerated; irrelevant schemas (public, neuroassist_global) are not in the result

## Resultado esperado

On a DB with t_unitA and t_unitB (and neuroassist_global), TenantSchemaEnumerator.list() returns ["t_unitA", "t_unitB"]. On an empty DB, returns [].

## Criterios de aceite
- [ ] AC-1 Returns only schemas matching the configured prefix (default t_)
- [ ] AC-2 neuroassist_global, public, and other non-tenant schemas are excluded from the result
- [ ] AC-3 Empty result (zero tenant schemas) is a valid non-error return
