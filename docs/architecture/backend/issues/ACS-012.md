## Contexto

Tenant onboarding is the entry point for the multi-tenant model. Only `platform-ops` may
call it (INV-5); any other token (including caregiver tokens with any authority) must be
rejected with 403. The `platform-ops` token carries no `tenantId` claim.

The service:
1. Inserts the `tenant` row in `neuroassist_global` schema.
2. Signals MIG to provision the `t_<tenantId>` schema (apply V0011 template).
   For the MVP, this is modeled as a port call (MIG integration port) since MIG runs
   centralized Flyway; the adapter for this port is deferred to INT-ACS-003.
3. Audits `TenantOnboarded` via `HistAuditPort` (grant action).

Caller authorization is enforced by `@PreAuthorize(RoleAuthorityPolicy.TENANT_ONBOARD)`
on the controller (ACS-004), plus a domain-level guard against null-tenantId callers.
