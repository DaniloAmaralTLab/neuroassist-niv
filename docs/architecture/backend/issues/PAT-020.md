## Contexto

Implements `X-Correlation-Id` propagation and structured JSON logging. `CorrelationIdFilter`
reads `X-Correlation-Id` from the inbound request (or generates one if absent, as GWY
normally provides it), stores it in MDC as `correlationId`, and echoes it on every response
and on every HIST audit call (api-contract §0.1). `MdcContextFilter` additionally stores
`tenantId` and `actorId` in MDC. `logback-spring.xml` outputs structured JSON with fields
`correlationId`, `tenantId`, `actorId`, `action` — MUST NOT include `patient.label` or
`command.label` (PHI minimization, SPEC-07).
