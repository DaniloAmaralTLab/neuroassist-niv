# MIG-005 -- FlywayRunner — programmatic Flyway instance per schema (SPEC-02)

**Status:** INTACT -- gerado 2026-11-22
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/4 itens

## Contexto

Spring Boot auto-configuration only manages a single Flyway instance against one schema. MIG must run Flyway against N+1 schemas (1 global + N tenant) in a single invocation. FlywayRunner builds a per-schema Flyway instance programmatically, pointing it at the correct classpath location (db/migration/global for global schemas, db/migration/tenant for tenant schemas) and setting the search_path for tenant runs (INV-MIG-5).

## Spec de referencia
- SPEC-02 (FlywayRunner role, one instance per schema)
- SPEC-05 (validateOnMigrate=true, outOfOrder=false)
- contracts/integration-contracts.md §2 (classpath locations)

## Escopo
- `services/neuroassist-niv-migrations/src/main/java/com/neuroassist/migrations/infrastructure/FlywayRunner.java` — buildGlobalFlyway(DataSource, String globalSchema) and buildTenantFlyway(DataSource, String tenantSchema, String globalSchema); both set validateOnMigrate=true, outOfOrder=false; tenant instance sets search_path=[tenant, neuroassist_global]
- `services/neuroassist-niv-migrations/src/main/java/com/neuroassist/migrations/domain/MigrationResult.java` — record: schema, fromVersion, toVersion, success, failureMessage
- `services/neuroassist-niv-migrations/src/test/java/com/neuroassist/migrations/infrastructure/FlywayRunnerTest.java` — Testcontainers: global location applied; tenant location applied with correct search_path; re-run is no-op (exit 0)

## Resultado esperado

FlywayRunner.runGlobal() applies db/migration/global scripts to neuroassist_global and returns MigrationResult(success=true). FlywayRunner.runTenant("t_unitA", "neuroassist_global") applies db/migration/tenant scripts to t_unitA with neuroassist_global on search_path.

## Criterios de aceite
- [ ] AC-1 Global Flyway instance uses classpath:db/migration/global against neuroassist_global; validateOnMigrate=true; outOfOrder=false
- [ ] AC-2 Tenant Flyway instance uses classpath:db/migration/tenant against t_<tenantId> with search_path=[t_<tenantId>, neuroassist_global]
- [ ] AC-3 Re-running FlywayRunner against an already-migrated schema returns MigrationResult(success=true, pendingMigrations=0) — no-op
- [ ] AC-4 `./gradlew :services:neuroassist-niv-migrations:test` exits 0
