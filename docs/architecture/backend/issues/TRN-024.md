## Contexto
Implement the main publication pipeline and its REST controller. `POST /trn/proposals/{id}/publication` triggers: (1) consent check, (2) `TtsPort` synthesis per approved phrase, (3) `SearchIndexPort` index, (4) `TreePublicationPort` publish to CONV. Steps 2-4 run as `outbound_job` entries dispatched by `OutboundJobDispatcher` (TRN-023). The endpoint returns `202 Accepted` immediately with a `pending` publication record. The idempotency key `trn:publish:<approvalId>` ensures at-most-one publication per approval (INV-TRN-6). No phrase is published to CONV without an available `audio_asset` reference in the manifest (INV-TRN-4). `ContentPublished` is a hard-502 HIST fact.
