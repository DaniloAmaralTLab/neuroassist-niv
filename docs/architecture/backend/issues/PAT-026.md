# PAT-026 -- Durable audit retry for PatientDeactivated (HIST ADR-005 commit+durable-retry)

**Status:** INTACT -- gerado 2026-11-20
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/4 itens

## Contexto

HIST ADR-005 (accepted, Option B) reclassifies **`PatientDeactivated`** as **commit+durable-retry**
(ACCESS-END — deactivation ends monitoring/access and must not be blocked by an audit-sink outage).
PAT previously treated every fact as hard-502; this issue adds the durable-retry path for the single
access-ending fact. All other PAT facts (`PatientRegistered`, `PatientReactivated`, `CommandCalibrated`,
`CommandRetired`, `GestureTypeRegistered`) stay hard-502 and are unchanged.

Durable-retry contract (HIST event-contracts §3): commit-first (commit the deactivation before the
audit write), local durable store (an outbox-style table — messaging is disabled, no broker),
idempotent replay with an explicit `idempotencyKey` (ADR-003), bounded with backoff + a backlog alert,
dev log-only.
