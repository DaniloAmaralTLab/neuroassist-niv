## Contexto

ArchUnit test class that enforces the hexagonal architecture rules across the
`com.neuroassist.acs` package tree. These rules catch regressions that would otherwise
compile but violate the architecture:

- **RULE-01**: `domain.**` must not import from `org.springframework` or `jakarta.persistence`
- **RULE-02**: `domain.**` entities must not have JPA annotations
- **RULE-03**: `api.**` and `infrastructure.**` must not be depended on by `domain.**`
- **RULE-04**: `application.**` must not import `infrastructure.**` (only ports)
- **RULE-05**: `@Transactional` must not appear in `domain.**` or `infrastructure.**`
- **RULE-06**: `api.**` must not access `infrastructure.**` directly (must go through `application.**`)
- **RULE-07**: All `@PreAuthorize` in `api.**` must reference `RoleAuthorityPolicy` constants
  (textual: source string contains `RoleAuthorityPolicy.`)
- **RULE-08**: `application.port.out.**` must only contain interfaces, no concrete classes

Runs in the `test` scope (plain unit, no Spring context required).
