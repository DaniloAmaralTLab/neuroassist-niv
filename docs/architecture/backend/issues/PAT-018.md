## Contexto

Implements two security guards. `PatientSessionTokenFilter`: inspects the JWT `actorType`
claim; if `actorType == patient-session`, rejects the request with `403 Forbidden` on every
`/pat` endpoint (INV-PAT-7, ACS INV-3). `TenantIsolationAspect` (or repository-level guard):
ensures that any resource lookup scoped to the caller's tenant returns `404` when the
resource belongs to a different tenant, without revealing the resource's existence
(INV-PAT-2). `SecurityIT` runs integration tests covering both guards with real Spring context
and mock JWT tokens.
