## Contexto
Implement the application service and REST controller for creating and reading training sessions (api-contract §2). Opening a session resolves the patient via `PatientReferencePort` (ETag/304) to verify existence and tenant membership, creates the `training_session` row, and immediately audits `TrainingSessionStarted` to HIST via `AuditPort.auditHard502()`. On HIST failure: roll back the session creation and return `502 audit-unavailable`. `TenantContextHolder.require()` is the first line of `SessionService`.
