## Contexto
Implement caregiver-confirmation (§4.1) and patient-assent (§4.2) domain-fact endpoints, plus the dual-authorization enforcement. When both halves are present and recorded by **distinct actors**, `ProposalApproved` is raised and audited to HIST via `AuditPort.auditHard502()`. On HIST failure: roll back the approval and return `502 audit-unavailable`. Patient assent is a domain fact — not an OAuth `trn.*` authority (ACS INV-3). Guardian-substitute assent is handled by the same endpoint with an additional `guardianId` field.
