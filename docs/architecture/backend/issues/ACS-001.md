**Status:** INTACT -- gerado 2026-11-19

## Contexto

Foundation issue. Creates the four-layer package skeleton (api / application / domain /
infrastructure) for `acs-service` and the Gradle build file with the `integrationTest`/`test`
split required by D-636: without `tasks.test { exclude("**/*IT.class") }`, the plain `test`
task picks up `CucumberIT` and similar IT classes, which require the full Spring context and
cascade into `DefaultCacheAwareContextLoaderDelegate` failures for every unimplemented port
(expected at P1). `application.yml` wires port 8081, Eureka and datasource stubs.
