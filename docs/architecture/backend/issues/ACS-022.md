# ACS-022 -- MDC correlation + structured logging (CorrelationIdFilter only — no duplicate MVC interceptor)

**Status:** INTACT -- gerado 2026-11-19
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/3 itens

## Contexto

Structured logging with Logback + JSON layout (Logstash-compatible) so that all log lines
carry `correlationId` and `tenantId` from the MDC.

The `CorrelationIdFilter` (ACS-019) already sets `MDC.put("correlationId", ...)`.
This issue adds:
- `logback-spring.xml` with a Logstash JSON appender that includes MDC fields.
- An MDC cleanup hook to prevent tenant/correlation ID leaks across threads.
- `tenantId` added to MDC by `TenantContextFilter` (ACS-017) after the JWT is resolved.

No second `CorrelationIdInterceptor` or `CorrelationIdMdcInterceptor` (pitfall
`scaffold:infrastructure-security:duplicate-correlation-id-mdc` confirmed in ACS-019;
this issue only adds the Logback config and MDC-cleanup).
