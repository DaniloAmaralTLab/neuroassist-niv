## Contexto

MIG's tests require a real PostgreSQL instance because they exercise CREATE SCHEMA, CREATE EXTENSION, and Flyway DDL. Testcontainers PostgreSQL (one container per test class) provides this. The BDD test infrastructure wires CucumberSpringContext + CucumberIT into the integrationTest source set so the four feature files can invoke MigrationsJobRunner directly (not via CLI exec) and assert exit code + DB state.
