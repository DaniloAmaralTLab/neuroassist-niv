## Contexto
Implement the Elasticsearch adapter for `SearchIndexPort` (authoring-side only — not on the patient live communication path). The adapter indexes only `approved`/`published` proposals (INV-TRN-5). Every ES query carries a `tenantId` filter (INV-TRN-8). An ES outage must NOT block a CONV publish: on ES 5xx, the adapter catches the exception and enqueues an `outbound_job` of type `index` for durable retry. When ES is fully degraded, the pg_trgm trigram index on `proposal.text` serves as a dedup fallback.
