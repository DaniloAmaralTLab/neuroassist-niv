## Contexto
Implement the GET, PATCH, and sub-resource transition endpoints for proposals (api-contract §3.2–3.5). The proposal state machine is enforced in the application layer: an illegal transition (e.g. PATCH on an `approved` or later proposal) returns `409 proposal-state-locked`. No controller may import from the `infrastructure.security` package.
