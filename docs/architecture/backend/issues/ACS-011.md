## Contexto

Manages the authorization edge `caregiver_patient_link` (tenant-scoped).

**Link:** creates the edge. If `(caregiverId, patientId)` already exists, returns 409
`link-exists` (idempotent SPEC-05 — does NOT create a duplicate). Validates that
`caregiverId` belongs to the caller's tenant (404 otherwise — no cross-tenant disclosure).
`patientId` is validated only by reference (PAT owns the patient aggregate; ACS stores the
id and trusts the caller's tenant context). Audit: `PatientLinked` (grant action).

**Unlink:** removes the row physically (the only table with hard deletes — data-model §1).
Returns 404 if link does not exist. Audit: `PatientUnlinked`.

**ListLinks:** returns `{ links: [{ patientId }] }` for a given caregiver within the
caller's tenant.
