## Contexto

When GWY short-circuits (edge check fails, rate limit exceeded, downstream unreachable,
circuit breaker open, response timeout), it must return a consistent, PHI-free JSON
body following RFC 7807 ProblemDetail. The body shape is defined in api-contract §6:
`type`, `title`, `status`, `detail` (generic, PHI-free), `correlationId`. The body
NEVER contains: request body, query values, token content, or any patient/device
identifier. Implements a reactive `ErrorWebExceptionHandler` (WebFlux, not MVC
`@ControllerAdvice`) that handles Spring Cloud Gateway's error types (e.g.
`ResponseStatusException`, resilience4j fallback exceptions).

- SPEC-01 (error model — PHI-free ProblemDetail)
- `contracts/api-contract.md` §6 (status codes and body shape)
- SPEC-06 (PHI-free posture — INV-G1)
