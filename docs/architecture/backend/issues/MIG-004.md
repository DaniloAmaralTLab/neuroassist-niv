# MIG-004 -- SchemaAdmin — CREATE EXTENSION and CREATE SCHEMA outside @Transactional (SPEC-02, INV-MIG-6)

**Status:** INTACT -- gerado 2026-11-22

## Contexto

DDL statements like CREATE SCHEMA and CREATE EXTENSION cannot run inside a transaction (they are auto-committed in PostgreSQL). Calling them from within a @Transactional method that also contains a Flyway invocation causes a deadlock because Flyway opens its own connection. SchemaAdmin solves this by executing DDL via raw JDBC on the admin datasource, never inside any Spring transaction (INV-MIG-6, doc 06 R5).
