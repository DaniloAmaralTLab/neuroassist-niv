## Contexto

Completes the API layer with the remaining 8 endpoints (commands + gesture-types). The
critical sub-feature is the **ETag/304 protocol** for catalog reads: `GET .../commands`
(§2.2) and `GET /pat/gesture-types` (§3.1) must return a strong ETag derived from the
resource version signature (`max(updated_at)` + count for commands; `max(created_at)` +
count for gesture-types), and honor `If-None-Match` with `304 Not Modified` (ADR-004, SPEC-03).
`CommandResponse` must resolve `primaryPrimitive`/`secondaryPrimitive` inline as
`{ id, code, displayName }` so detection agents need no second call (ADR-004 §G3).
All `@PreAuthorize` strings from `RoleAuthorityPolicy` (INV-PAT-8). API contract §2–3.
