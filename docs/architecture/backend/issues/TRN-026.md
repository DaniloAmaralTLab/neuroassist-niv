# TRN-026 -- CorrelationIdInterceptor + PrivacyLogFilter + TrnMetrics — X-Correlation-Id MDC + forwarding, PHI/LLM/voice scrubbing from logs, Micrometer outbound_job depth/error counters (SPEC-07, ADR-004/005)

**Status:** INTACT -- gerado 2026-11-22
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/4 itens

## Contexto
Add end-to-end correlation, privacy-safe logging, and operational metrics. `CorrelationIdInterceptor` reads/generates `X-Correlation-Id` on every inbound request, puts it in MDC, and forwards it on all outbound CONV/PAT/HIST/vendor calls. `PrivacyLogFilter` strips patient name, PHI, raw LLM content and voice data from log entries before they are written (ADR-004/005). `TrnMetrics` exposes Micrometer counters/gauges for `outbound_job` depth and attempts/failures by `job_type`, and per-port vendor latency/error counts.

## Spec de referencia
- SPEC-07 (X-Correlation-Id, structured logging, outbound_job metrics)
- ADR-004 (LLM data minimisation — no raw transcript in logs)
- ADR-005 (PHI/voice data must not appear in logs)
