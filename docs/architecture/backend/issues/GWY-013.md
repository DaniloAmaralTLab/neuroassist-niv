# GWY-013 -- Per-route circuit breaker + connect/response timeouts — resilience4j per downstream, 503 fallback when open, 504 on response timeout

**Done/Total:** 0/5 itens

## Contexto

Isolates a slow or failing downstream so it cannot hang the entire gateway
(ADR-006). Each of the 8 routes gets an independent resilience4j circuit breaker
(so a breaker-open on TRN does not affect HIST). Each route also has a connect
timeout (TCP connect) and a response timeout (read timeout). When the breaker
is open the gateway returns a fast, PHI-free 503 fallback without calling the
downstream. When the response timeout is exceeded the gateway returns 504.
Retry is intentionally scoped to a separate issue (GWY-014). All threshold values
(`slidingWindowSize`, `failureRateThreshold`, connect/response timeouts) are
configuration, not hard-coded.
