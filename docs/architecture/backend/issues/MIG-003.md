## Contexto

MigrationsJobRunner is the Spring CommandLineRunner that is the top-level orchestrator. It calls MigrationArgParser, dispatches to the appropriate pass sequence, aggregates MigrationResult values, and terminates the JVM with System.exit(0/1/2). This issue covers the skeleton + exit-code dispatch; the actual SchemaAdmin and FlywayRunner implementations are in MIG-004..MIG-006.

## Spec de referencia
- SPEC-01 (exit codes: 0 success/no-op, 1 usage error, 2 migration failure)
- SPEC-02 (orchestration sequence)

## Escopo
- `services/neuroassist-niv-migrations/src/main/java/com/neuroassist/migrations/application/MigrationsJobRunner.java` — implements CommandLineRunner; calls MigrationArgParser; delegates to MigrationOrchestrator (stub for now); calls System.exit with the correct code
- `services/neuroassist-niv-migrations/src/main/java/com/neuroassist/migrations/application/MigrationOrchestrator.java` — interface/stub; filled by MIG-006
- `services/neuroassist-niv-migrations/src/test/java/com/neuroassist/migrations/application/MigrationsJobRunnerTest.java` — unit tests: usage error -> exit 1; orchestrator success -> exit 0; orchestrator failure -> exit 2

## Resultado esperado

Running `./gradlew :services:neuroassist-niv-migrations:bootRun --args="--all"` reaches MigrationsJobRunner.run(), calls the stub orchestrator, and exits 0. Running with invalid args exits 1 without calling the orchestrator.
