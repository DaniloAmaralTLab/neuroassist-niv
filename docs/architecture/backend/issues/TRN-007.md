## Contexto
Implement the application service and REST controller for the assistant dialog turn (api-contract §3.1). The service calls `LlmDialogPort` with minimised context only: `patientId`, draft text, and the caregiver authoring prompt — never patient name or any PHI (INV-TRN-7). The model response is treated as untrusted data: it may only create or refine proposals in `draft`/`proposed` state (INV-TRN-2). The raw model transcript is never stored. On LLM vendor failure, return `503 llm-unavailable` without persisting a partial proposal.
