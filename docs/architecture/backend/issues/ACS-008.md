## Contexto

The anchor use case. When a caregiver provisions a patient session:
1. Validates `patientId` and `deviceId` belong to the caller's tenant (INV-2).
2. Mints a patient-session JWT via `TokenIssuerPort.issueSessionToken(...)` with:
   - `sub = session.id`, `actorType=patient-session`, `tenantId` from caller,
   - `authorities = ["conv.tree.navigate", "conv.node.select"]` ONLY (INV-3),
   - **no expiry** (non-expiring by design, ADR-003).
3. Saves the `PatientSession` row (with `token_jti` = JWT `jti`) atomically.
4. Calls `HistAuditPort.recordGrantAction(PatientSessionProvisioned, ...)` — if HIST fails,
   the use case rolls back and returns 502 (grant actions are not committed without audit).
