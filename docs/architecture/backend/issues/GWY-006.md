# GWY-006 -- TenantHeaderStripFilter — strip X-Tenant-Id (and tenant-ish variants) before forwarding (ADR-003, INV-G3)

**Maturidade:** 0 -- Inicial

## Contexto

Prevents tenant-header spoofing (Risk R5): a malicious client could send
`X-Tenant-Id: t_other_tenant` to try to cross-tenant boundaries. This filter strips
the header before it ever reaches a downstream service. Downstreams derive tenant
context exclusively from the signed JWT claim — never from a client-supplied header.
Strip any variant that resembles a tenant header (e.g. `X-Tenant-Context`, `X-Tenant`).
Implement as a `GlobalFilter` running after `CorrelationIdFilter` (lower precedence).
