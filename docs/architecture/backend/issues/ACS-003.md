# ACS-003 -- Domain ports — 7 outbound port interfaces (Repository, TokenIssuer, TokenBlacklist, HistAudit)

**Status:** INTACT -- gerado 2026-11-19
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/5 itens

## Contexto

Outbound port interfaces that define the contract between application services and
infrastructure adapters (RULE-03: application layer depends on ports, never on adapters).
No Spring/JPA annotations. Key design notes:
- `CaregiverRepositoryPort` must include `findByUsername(String)` for the global lookup table
  (INV-6 login resolution) in addition to tenant-scoped methods — but no `findByTenantId(UUID)`
  parameter, as the schema-per-tenant isolation is enforced by the data-source routing (D-534).
- `HistAuditPort` must distinguish access-ending vs grant actions via method signatures so the
  adapter can apply the correct resilience policy (integration-contracts.md §2.1).
- `TokenIssuerPort` must express both caregiver token and patient-session token minting as
  separate operations (INV-3: session JWT restricted to conv.*/gest.* only).
