## Contexto

Actuator endpoints that could echo configuration or secrets (e.g. `/actuator/env`,
`/actuator/configprops`, `/actuator/routes`) MUST NOT be publicly accessible (ADR-007).
Only `/actuator/health` (anonymous allow-list, gateway liveness probe) and
`/actuator/prometheus` (platform-internal, gateway metrics) are exposed. Prometheus
metrics include: per-route request count, latency histograms, 4xx/5xx counters,
circuit-breaker state, and rate-limit rejection counters (Micrometer via Actuator).
Readiness reflects JWKS reachability + Eureka registration.
