## Contexto
Create the Feign client for HIST (`POST /hist/audit`) and the `AuditAdapter` implementing `AuditPort`. The adapter distinguishes two failure classes (ADR-007):
- **hard-502** facts (TrainingSessionStarted, ConsentGranted, ProposalApproved, ContentPublished): on HIST 5xx, throw so the caller rolls back and returns 502.
- **commit+durable-retry** facts (ConsentRevoked, VoiceModelDeleted, ContentErased): on HIST 5xx, enqueue an `outbound_job` of type `audit` and let the caller succeed.
Base-url from `neuroassist.hist.base-url` (HIST port 8083).
