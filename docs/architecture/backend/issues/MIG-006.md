# MIG-006 -- MigrationsJobRunner orchestration: baseline → global pass → tenant pass (SPEC-02)

**Status:** INTACT -- gerado 2026-11-22

## Contexto

This issue wires the full MIG execution flow: SchemaAdmin.ensureBaseline() first, then FlywayRunner.runGlobal(), then (if the mode requires it) TenantSchemaEnumerator.list() followed by FlywayRunner.runTenant() for each schema. A global-pass failure aborts all tenant runs (INV-MIG-1). One tenant failure aborts remaining tenants and exits 2 naming the failing schema (ADR-005).

## Resultado esperado

--all on a fresh DB: neuroassist_global at target version, every t_* at target version, exit 0. --global-only: only neuroassist_global migrated, no t_* touched. Global failure stops all tenant passes. Single tenant failure names the schema in the exit-2 message.

## Criterios de aceite
- [ ] AC-1 --all applies global block first, then tenant-template set to every existing t_* schema (INV-MIG-1)
- [ ] AC-2 --global-only applies global block only; zero t_* schemas touched
- [ ] AC-3 Global pass failure causes immediate abort; zero tenant schemas touched; exit 2 names "neuroassist_global"
- [ ] AC-4 Single tenant failure (injected bad script in test) causes exit 2 naming that tenant schema; schemas processed before it are left in their applied state
- [ ] AC-5 --all on a fully up-to-date DB exits 0 (no-op per schema, INV-MIG-3)
