## Contexto

Creates the `Command` entity in the domain layer. A `Command` maps a facial gesture
(`GestureComposition`: required `primaryPrimitive`, optional distinct `secondaryPrimitive` —
INV-PAT-4) to a family-defined need, with its own `CalibrationWindow`
(`minGestureTimeMs > 0 AND maxGestureTimeMs >= min` — INV-PAT-3) and `Sensitivity`.
Lifecycle is `active` → `retired` (terminal, INV-PAT-5); there is no transition out of
`retired`. Primitive id references are opaque UUIDs (no FK to `gesture_type` from the domain
entity — application-layer validation — G2). Data model in `contracts/data-model.md §2.3`.
