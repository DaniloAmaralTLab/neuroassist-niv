# GWY-004 -- Multi-issuer JWT — ReactiveAuthenticationManagerResolver, ACS + EDGE jwk-set-uri, exp-less validator (Risk R2), 401 proof test (D-642)

## Contexto

Replaces the single-issuer stub from GWY-003 with a two-issuer trust fabric (ADR-002,
INV-G6). Spring's standard `spring.security.oauth2.resourceserver.jwt.jwk-set-uri`
accepts only one JWKS; for two issuers (ACS + EDGE) a
`ReactiveAuthenticationManagerResolver<ServerWebExchange>` must route by the `iss`
claim to the matching `ReactiveJwtDecoder`. Each decoder is built with
`NimbusReactiveJwtDecoder.withJwkSetUri(...)`.

A custom `OAuth2TokenValidator<Jwt>` skips `JwtTimestampValidator` when the `exp`
claim is absent — patient-session tokens are non-expiring by design (ACS §4.1, Risk R2).

**D-642 mandate:** this issue must ship a mandatory integration test that proves a
protected route returns 401 without a valid token and admits one with a valid token.
An ACS-signed and an EDGE-signed token must both be tested (Risk R1).
