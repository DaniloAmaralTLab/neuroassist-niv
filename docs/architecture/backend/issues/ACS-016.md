## Contexto

Implements `HistAuditPort` via a Feign client to `hist-service` (discovered via Eureka,
service id `hist-service`, base URL property `neuroassist.hist.base-url`).

Resilience contract (integration-contracts.md §2.1 and §3):
- **Grant actions** (CaregiverRegistered, PatientLinked, TenantOnboarded, PatientSessionProvisioned):
  2s timeout; circuit breaker opens after 5 consecutive failures; on open → 502 error raised
  to caller; use case NOT committed.
- **Access-ending actions** (CaregiverDeactivated, PatientSessionRevoked, CaregiverAuthenticated):
  2s timeout; on failure → commit the local state change and enqueue the audit in
  `AuditRetryQueue` (ACS-024) for async retry.

The `HistClientConfig` class must annotate its `@Bean` methods (pitfall
`be:feign-client-config:methods-missing-bean-annotation` — a config class without `@Bean`
produces dead code that Spring Cloud OpenFeign silently ignores).
