## Contexto

Sets up the Cucumber/JUnit 5 BDD wiring for `pat-service`. `CucumberIT` is the test runner
(annotated `@CucumberOptions`, tagged as `integrationTest` so the plain `test` task excludes
it — PAT-001). `application-test.yml` configures EmbeddedPostgres (or `zonkyio`), WireMock
for ACS JWKS and HIST, and disables Flyway at start (migrations applied by test setup).
`CommonSteps` holds the reusable step definitions from SPEC-08: JWT token factories for
caregiver, patient-session and service-client tokens; tenant fixtures T1/T2; primitive seeds
(BLINK, EYEBROW_RAISE, DOUBLE_BLINK).
