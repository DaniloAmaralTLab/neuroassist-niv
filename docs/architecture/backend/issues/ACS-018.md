# ACS-018 -- TokenIssuer adapter — JWT minting with JWK signing key (caregiver + patient-session tokens, no expiry for sessions INV-3)

## Contexto

Implements `TokenIssuerPort` using Spring Security's `NimbusJwtEncoder` (or equivalent).
Key rules:

- **Caregiver tokens**: include `sub=caregiverId`, `tenantId`, `actorType=caregiver`,
  `authorities` from `RoleAuthorityPolicy` per the caregiver's role, standard `exp` claim.
- **Patient-session tokens**: include `sub=sessionId`, `tenantId`, `actorType=patient-session`,
  `authorities=["conv.tree.navigate","conv.node.select"]` ONLY (INV-3), and **NO `exp` claim**
  (non-expiring by design — ADR-003). An `exp` claim would contradict the non-expiring contract.
- Signing key loaded from `ACS_JWT_KEY_PATH` env var (dev PEM key — setup-local.md).
- The `JwksController` (served at `/acs/.well-known/jwks.json`) calls `TokenIssuerPort.getPublicJwks()`
  to serve the JWKS document; resource servers cache it.
