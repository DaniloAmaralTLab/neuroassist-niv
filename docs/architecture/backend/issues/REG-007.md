## Contexto
The Prometheus metrics endpoint exposes registry-level operational metrics: number of registered apps/instances, renewal rate (renewals/min), eviction count, and self-preservation active flag. These metrics are the signal for deciding when to enable peer HA (ADR-001) and for detecting stale instances.
