# MIG-015 -- RangeRegistry guard — load migration_range_registry and assert no overlapping blocks before apply (SPEC-04, INV-MIG-2)

**Maturidade:** 0 -- Inicial
**Done/Total:** 0/4 itens

## Contexto

Reserved blocks must not overlap on any version number (INV-MIG-2). The DB enforces no-duplicate-start via UNIQUE(owner_module, block_from) but cannot enforce non-overlap across different starts. RangeRegistry.java runs after the baseline (migration_range_registry exists and is seeded) and before any module block is applied. It reads all confirmed=TRUE rows, checks for version-range overlaps, and throws MigrationRangeCollisionException if any two confirmed blocks share a version number. Unconfirmed (proposed) blocks are excluded from the check (they are not yet numbered on disk).
