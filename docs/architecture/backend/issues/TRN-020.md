# TRN-020 -- SecurityConfig — OAuth2 resource server (ACS JWKS), JwtAuthenticationConverter (authorities claim), @EnableMethodSecurity(prePostEnabled=true) (D-642, SPEC-06)

## Contexto
Configure Spring Security as an ACS resource server: validate the caregiver JWT via ACS JWKS, map the `authorities` claim with `JwtAuthenticationConverter` (the standard Spring Security converter for flat authority lists), and require `@EnableMethodSecurity(prePostEnabled=true)` for `@PreAuthorize` to be active (D-642 — without this annotation the @PreAuthorize guards are silently inert). Public path: `GET /trn/health` only. A patient-session token (authorities restricted to `conv.*`/`gest.*`) must be rejected 403 on every protected `/trn` endpoint (ACS INV-3).
