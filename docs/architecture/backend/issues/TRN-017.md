# TRN-017 -- AnthropicLlmDialogAdapter — minimised context (patientId only, no PHI), INV-TRN-2 state ceiling, vendor 5xx→503 (SPEC-02, SPEC-10, ADR-004)

**Status:** INTACT -- gerado 2026-11-22
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/4 itens

## Contexto
Implement the Anthropic Claude adapter for `LlmDialogPort`. The adapter constructs the API request with ONLY minimised context fields: `patientId`, draft category/phrase text, and the caregiver authoring prompt — never a patient name, PHI or free-text identifier (INV-TRN-7). The model response is validated to ensure no proposal state beyond `proposed` is requested (INV-TRN-2). An Anthropic 5xx/timeout returns `503 llm-unavailable` without retrying (the session remains resumable from the last saved dialog state). No raw model transcript is stored.
