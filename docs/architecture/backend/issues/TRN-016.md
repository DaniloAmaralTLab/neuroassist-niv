## Contexto
Create the Feign client for CONV and the `TreePublicationAdapter` implementing `TreePublicationPort`. The client must implement three operations: `publish` (POST `/conv/trees` with idempotency key `trn:publish:<approvalId>`), `retire` (POST `/conv/tree-versions/{id}:retire`), and `eraseAudio` (DELETE `/conv/patients/{id}/audio`). Publish is idempotent: a 200 replay from CONV (same `idempotencyKey`) is treated as success. A `422 dangling-audio-reference` from CONV propagates as a domain exception (not silently swallowed — INV-TRN-4). Base-url from `neuroassist.conv.base-url` (CONV port 8085).
