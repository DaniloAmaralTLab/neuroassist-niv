## Contexto

Implements the two ACS infrastructure adapters. `JwksTokenValidationAdapter` implements
`TokenValidationPort`: fetches and caches the JWKS from `GET {acs.baseUrl}/acs/.well-known/jwks.json`,
verifies JWT signatures; falls back to last cached keys on outage (never accepts unsigned
tokens — integration-contracts §1). `AcsIntrospectionAdapter` implements `AcsIntrospectionPort`:
calls `POST {acs.baseUrl}/acs/auth/introspect` on state-changing operations; on outage,
standard JWT validation still applies (best-effort revocation + logged). Service discovery
via REG (Eureka); direct `acs.base-url` as fallback. See INT-PAT-001 for the open question
on service-client token minting.
