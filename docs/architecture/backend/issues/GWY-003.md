## Contexto

Creates the WebFlux security configuration wiring the anonymous allow-list and
deny-by-default posture. Framework gap (integration-contracts §7): the generated
gateway template emits `permitAll` for `actuator/health` and `actuator/prometheus`
only, and wires a **single** `issuer-uri`. This issue replaces the stub with the
full public-paths `permitAll` from `generator-config.yml` and stubs in the
JWT `oauth2ResourceServer` hook (the multi-issuer resolver is wired by GWY-004).
GWY is WebFlux — the annotation is `@EnableWebFluxSecurity` and the bean type is
`SecurityWebFilterChain`, NOT `@EnableMethodSecurity` (that is for resource servers
running in servlet mode — D-642 inverted: the gateway's check is proven by 401).
