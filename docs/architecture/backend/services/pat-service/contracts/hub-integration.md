# PAT — TechLab AI Hub Integration

> Service: `pat-service` · Module **PAT — Patients and Command Catalog** · Project: NeuroAssist NIV

## Summary

**PAT has no TechLab AI hub dependency.** The project does not integrate the TechLab AI
hub: `ai.hasAi = false`, and the `/new-project` phase `P3-techlab-ai-sync` is `skipped`
(see `project-context.json` → `setup.phases`). There is therefore no docs snapshot under
`integrations/techlab-ai/` and no Feign client to a hub bounded context.

| Hub bounded context | Used by PAT? |
|---|---|
| orchestration | no |
| knowledge | no |
| document_composition | no |
| analytics | no |

## Propagation headers (for intra-project calls)

Although there is no hub, PAT still propagates the standard correlation header on its
outbound synchronous calls (PAT → ACS JWKS/introspect; PAT → HIST audit — see
`integration-contracts.md`):

- `X-Correlation-Id` — echoed from the inbound request; generated by GWY if absent.
- Tenant and principal context travel inside the ACS-issued JWT (`tenantId`, `sub`,
  `actorType`), not as separate headers; `X-Tenant-Id` is never trusted (INV-PAT-1).

If the hub is later adopted (institutional expansion), this file is where the Feign
operations, fallbacks and consumed hub events would be documented.
