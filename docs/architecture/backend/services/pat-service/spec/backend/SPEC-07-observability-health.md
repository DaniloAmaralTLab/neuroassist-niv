# SPEC-07 — Observability and health

> Service `pat-service` · Module **PAT** · EARS guide: `../../../../standards/ears-notation.md`

## Objetivo

Specify correlation propagation, logging, health and metrics so PAT is operable within the
internal-network constraint, without leaking PHI.

## Escopo

- **In:** `X-Correlation-Id` propagation, structured logging, Actuator health/readiness,
  metrics, the PHI-minimization rule.
- **Out:** centralized log aggregation stack (ops concern, not this service's contract).

## Decisões técnicas

- `X-Correlation-Id` generated by GWY if absent; PAT echoes it on every response and on every
  HIST audit call (api-contract §0.1).
- Logs are structured (JSON) and carry `correlationId`, `tenantId`, `actorId`, `action`.
- Health via Spring Boot Actuator: liveness, readiness (readiness includes DB connectivity;
  ACS JWKS reachability is a degraded-but-serving signal, not a hard readiness fail — cached keys).

## Implementação

- `GET /actuator/health` (liveness/readiness), `GET /actuator/info`, Micrometer metrics.
- Per-use-case metric counters (`pat_command_calibrated_total`, `pat_patient_registered_total`,
  `pat_catalog_read_total`, `pat_catalog_read_304_total`) + HIST-audit success/failure counters.
- **PHI minimization:** the only free-form, family-authored field is `command.label` /
  `patient.label`; logs and metrics SHALL NOT emit label contents — ids and counts only.

## Casos de borda

- HIST unreachable → audit-failure counter increments; hard-502 facts return `502 audit-unavailable`
  in prod and `PatientDeactivated` commits + enqueues an idempotent durable retry
  (event-contracts §1, HIST ADR-005), log-only in dev profile.
- ACS JWKS briefly unreachable → readiness stays UP on cached keys; a JWKS-stale gauge is exposed.

## Critérios de aceite (EARS)

- THE SYSTEM SHALL propagate and echo `X-Correlation-Id` on every response and every HIST audit call.
- THE SYSTEM SHALL expose Actuator health with a readiness check that fails when the database is unreachable.
- THE SYSTEM SHALL NOT emit the contents of `patient.label` or `command.label` to logs or metrics (PHI minimization).
- WHEN a HIST audit call fails, THE SYSTEM SHALL increment an audit-failure metric carrying the `correlationId`.
