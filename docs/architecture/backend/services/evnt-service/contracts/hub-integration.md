# EVNT — TechLab AI Hub Integration

> Service: `evnt-service` · Module **EVNT — Events and Alarms** · Project: NeuroAssist NIV

## Summary

**EVNT has no TechLab AI hub dependency.** The project does not integrate the TechLab AI hub:
`ai.hasAi = false`, and the `/new-project` phase `P3-techlab-ai-sync` is `skipped`. There is no docs
snapshot under `integrations/techlab-ai/` and no Feign client to a hub bounded context.

| Hub bounded context | Used by EVNT? |
|---|---|
| orchestration | no |
| knowledge | no |
| document_composition | no |
| analytics | no |

EVNT turns a recognized gesture into a structured Event and orchestrates pull-based delivery; it runs
no AI. Detection/classification is on the edge (GEST/EDGE truth); EVNT trusts the resolved
`commandId` (doc 04).

## Propagation headers (for intra-project calls)

Although there is no hub, EVNT propagates the standard correlation header on its outbound synchronous
calls (EVNT → PAT command read; EVNT → EDGE introspection; EVNT → ACS JWKS/introspect/links; EVNT →
HIST audit — see `integration-contracts.md`):

- `X-Correlation-Id` — echoed from the inbound request; generated by GWY if absent.
- Tenant and principal context travel inside the token (`tenantId`, `sub`, `actorType`), not as
  separate headers; `X-Tenant-Id` is never trusted (INV-EVNT-1).

If the hub is later adopted, this file is where the Feign operations, fallbacks and consumed hub
events would be documented.
