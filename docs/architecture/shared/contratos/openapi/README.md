# OpenAPI Specs

Folder for the OpenAPI files (`*-openapi.yaml`) **generated** by each microservice.

> ⚠️ **These files are not handwritten.** They are generated by `springdoc-openapi` in each service and copied here by CI (or by `/be-architect-specs`).

## How to generate/update

### Local (1 service)

```bash
# Start the service
./gradlew :<service>:bootRun

# In another terminal, download the spec
curl http://localhost:8082/v3/api-docs.yaml > docs/architecture/shared/contratos/openapi/cadastros-openapi.yaml

# For all services at once (utility script):
python scripts/gh_pipeline.py openapi-dump --all
```

### CI

The `openapi-sync` job (`.github/workflows/openapi.yml`) starts each service, downloads the spec, and opens a PR if anything changed.

## When to update

- Added a new REST endpoint to the controller → regenerate the affected service's spec.
- Changed the shape of a DTO (record record-class) → regenerate.
- Added/removed/renamed an `error.code` → update but also check `error-model.md`.

## Consumption by the Frontend

The frontend generates TS SDKs from these YAMLs:

```bash
# In frontend/
npm run gen:sdk:cadastros
# → libs/shared/contracts/src/lib/cadastros/ (interfaces + typed ApiServices)
```

Angular components consume:

```typescript
import { CadastrosApi, ClienteResponse } from '@neuroassist/shared/contracts/cadastros';
```

## Conventions in the spec

Configured via `springdoc.application.yml` in each service:

- `info.title` = `<Modulo> Service API` (e.g. `Cadastros Service API`)
- `info.version` = build version (e.g. `1.4.2`)
- `info.contact.email` = `arquitetura@neuroassist-niv.local`
- `servers[0].url` = `/api/<modulo>` (behind the gateway)
- `tags` = groups per resource (`Clientes`, `Produtos`, `Fornecedores`)
- `components.schemas.ProblemDetail` = always included (referenced in the error-model)
- `security` = `bearerAuth` on all endpoints (except `/health`, `/info`)

## Anti-patterns

- ❌ Editing the YAML by hand (changes are lost on the next generation).
- ❌ Versioning cosmetic diffs (formatting) — use `npm run format:openapi` before committing.
- ❌ Mixing specs of different versions (always the current spec from `main`).
